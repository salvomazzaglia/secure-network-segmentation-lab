# Segmentation model

Six fictional security segments:

| Segment | Demo VLAN | Logical prefix | Tier |
|---------|-----------|----------------|------|
| management | 210 | SEGMENT-NET-210 | privileged |
| infrastructure | 220 | SEGMENT-NET-220 | privileged |
| trusted | 230 | SEGMENT-NET-230 | standard |
| iot | 240 | SEGMENT-NET-240 | restricted |
| guest | 250 | SEGMENT-NET-250 | restricted |
| quarantine | 260 | SEGMENT-NET-260 | isolation |

All VLAN IDs are labeled **SYNTHETIC VLAN ID — EXAMPLE ONLY**.

Selected demo IPv4 maps use documentation ranges only. Segmentation is a logical security construct, not a claim about production campus design.
