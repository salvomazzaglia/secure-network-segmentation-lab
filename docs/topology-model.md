# Topology model

## Nodes

`node_id`, `device_id`, `node_type`, `label`, `segment`, `device_class`, confidence, connection type, security state, online, last seen, metadata/position sources, illustrative coordinates.

## Edge types

`wired`, `wireless_association`, `logical_upstream`, `segment_membership`, `observed_communication`, `allowed_policy_path`, `denied_policy_path`.

## Provenance

Every edge/node fact retains provenance. Do not merge categories invisibly.

## Visualization note

Positions and edge lengths are normalized for display. No physical cable-length estimation is performed.
