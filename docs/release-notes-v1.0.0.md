# Release notes — v1.0.0

Initial public release of **secure-network-segmentation-lab**.

## Highlights

- Offline-first synthetic segmentation laboratory
- Explainable classification and confidence scoring
- Declarative segmentation and reachability policies
- Quarantine and approval simulation (no enforcement)
- Topology, wireless buckets, and illustrative 3D map
- REST API, WebSocket events, CLI
- Privacy guards, JSON schemas, example reports, GitHub CI

## Safety statement

Version 1.0 never applies network changes. All VLAN transitions, approvals, quarantine actions, and reachability policies are simulated or proposed only.

## Known limitations

- No live adapters or enforcement
- Confidence is heuristic, not probabilistic
- 3D placement is illustrative only
- Reachability models intended policy, not live firewall state
