# Wired topology

Wired edges model switch/port attachment and uplinks across synthetic core/edge switches.

## Rules

- Edge length is not cable length
- Port IDs are fictional labels (`Gi1/0/21` style demos)
- LLDP/FDB imports (future) must be sanitized; malformed imports are rejected
- Multi-switch paths are logical teaching aids

UI provides text topology paths in addition to 3D views.
