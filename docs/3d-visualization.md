# 3D visualization

The dashboard includes an interactive Three.js security map for teaching segmentation concepts.

> Spatial placement is illustrative. It represents logical relationships, security segmentation, and relative wireless quality — not measured physical location.

## Design principles

- Logical, deterministic layout
- Security-zone clustering by segment
- Wireless illustrative positioning by signal bucket
- RSSI quality bands (not meters)
- No triangulation, floor plan, or cable-length claims
- Topology provenance visible in detail panels
- Visualization uncertainty communicated in UI copy

## View modes

Topology, segmentation, classification, security state, wireless, policy reachability, services.

## Accessibility

3D is never the only inspection path. Inventory tables, matrices, and text paths remain available. Respect reduced-motion preferences.
